1.上传文件

记住push文件时，用户名为邮箱；密码为申请的token

mkdir warehouse
cd warehouse
git init (在要上传文件那里init就行)
touch read.md
git add read.md
(git add .) 把全部文件都添加进去
git commit -m "first commit"
git remote add origin https://
git push -u origin "master" ($ git remote remove origin)

2.解决报错：recv failure connection was res
git config --global --unset http.proxy 
git config --global --unset https.proxy

3.设置用户：
# 设置用户名
git config --global user.name "xiaoli"
# 设置邮箱
git config --global user.email "3339059430@qq.com"

4.·更新文件

git add .
git commit -m "second commit"
git push 

5.下载文件到本地
git clone https://

6.创建branch
git branch -a    //查看有哪些分支
git checkout -b branchNameHere    //创建分支
git checkout 分支名 //分支切换
前面文件去缓存都一样，关联仓库时，git push -u origin "分支名"

git merge 分支名 --no-ff  //在master进行
git push //在master进行 
git branch -d branchNam //删除分支

6.查看历史版本并恢复
git log --oneline
git checkout -b old_version 版本哈希
git push -u origin old_version

7.更新github上的代码到本地
git pull origin master
